# Perfect World Web

**Research and engineering workspace** for a browser-native MMORPG client. The goal is to evaluate a genuine WebAssembly port of the Perfect World client and Angelica engine, without game streaming or Windows emulation.

> **Status: bootstrap / feasibility research.** This repository does not yet contain a playable Perfect World port.

The third-party code is isolated and referenced as pinned Git submodules. It is not automatically downloaded during ordinary checkout. **Public access to game source code is not a grant of rights to redistribute, modify, or commercialize it.** Do not merge, publish or bundle third-party game code/assets without verified permission.

See [Onboarding](docs/ONBOARDING.md), [Architecture](docs/ARCHITECTURE.md), [Roadmap](docs/ROADMAP.md), and [Third-party rights](docs/LEGAL.md).
