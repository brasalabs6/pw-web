# Agent skills (singular .agent)

`.agent/skills/` contains **operational conventions** read by all human and AI contributors, regardless of tooling. This is separate from:

- `.agents/epics/`: versioned workorders, dependencies and executable governance.
- `.grok/agents/`: Grok Build system instructions for coder and two reviewers.

Before creating or updating any pull request, read **[create-pr](skills/create-pr/SKILL.md)**.
Grok coder/publisher: instructions are also linked from the repository root `AGENTS.md`.
